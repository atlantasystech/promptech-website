# Promptech - Practical IT Services Single-Pager Website

A modern, high-performance single-page website built with **Next.js (App Router)** and **Vanilla CSS** for **Promptech**.

Promptech provides reliable, straightforward IT execution without overblown marketing buzzwords:
1. **Open Source Software Customization**: ERPNext, Odoo Community, WordPress/WooCommerce, Strapi/Directus, Docker, Linux VPS self-hosting, and data migrations.
2. **Digital Marketing Services**: Technical SEO audits, Core Web Vitals optimization, disciplined Google & Meta search ad management, and GA4 / conversion tracking.
3. **Offshore Development**: Dedicated remote engineers, full-stack web/API development (Next.js, React, Node.js, Python, PHP), with overlapping hours, fluent English, and daily Git commits.

---

## Key Features & Highlights

- **Safe, Grounded Copywriting**: Adheres strictly to realistic, safe language with no hyperbolic promises or inflated jargon.
- **Visual Excellence**: Custom high-resolution isometric tech graphics, deep slate theme (`#0b0f19`), subtle ambient glows, and glassmorphic card surfaces.
- **Interactive Scope & Estimate Calculator**: Allows prospective clients to explore typical timeframes, hours, and concrete deliverables, with a one-click button to transfer details into the inquiry form.
- **Interactive Consultation Form**: Validated inquiry form with instant submission confirmation, reference ID generation, and direct email contacts.
- **Transparent Comparison Table**: Direct contrast between traditional overblown agency promises and Promptech's grounded, client-owned approach.
- **Honest FAQ**: Clarifies IP ownership, no-guarantee search ranking truths, timezone collaboration, and 30-day post-launch warranty.
- **SEO & Performance**: Semantic HTML5 tags, comprehensive meta descriptions, and OpenGraph tags.

## Getting Started

### Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) to view the live website in your browser.

### Production Build
```bash
npm run build
npm run start
```
